# AI Coding Agent — VS Code Extension

Embeds the React UI inside a VS Code sidebar panel via a **WebviewViewProvider**
and provides one-click launch of the local FastAPI backend from the repo's `.venv`.

---

## Requirements

| Requirement | Details |
|---|---|
| VS Code | ≥ 1.90 |
| Node.js  | ≥ 18 (for extension packaging) |
| Python   | Managed via repo `.venv` (uv / pip) |

---

## Quick start

### 1 — Build the React UI (once, and after any UI changes)

```bash
cd ui
npm install
npm run build
# Produces:  ui/dist/index.html  and  ui/dist/assets/*
```

### 2 — Install the extension (development mode)

Open the repository root in VS Code, then press **F5** (or use
*Run → Start Debugging*) to launch an Extension Development Host.

Alternatively, package and install the `.vsix`:

```bash
cd vscode-extension
npm install          # installs @vscode/vsce devDependency
npx vsce package     # produces coding-agent-0.1.0.vsix
```

Then in VS Code: **Extensions → Install from VSIX…** → pick the generated file.

### 3 — Start the API server

Click the ✨ star icon in the Activity Bar to open the **AI Coding Agent** panel,
then either:
- Accept the prompt that appears on activation ("Start API"), or
- Open the Command Palette (`Ctrl+Shift+P`) and run **AI Coding Agent: Start API Server**.

This opens a dedicated terminal running:

```
<.venv>/Scripts/python.exe -m uvicorn interfaces.api_server:app \
    --host 127.0.0.1 --port 8000 --reload
```

### 4 — Chat in the sidebar

The ✨ sidebar panel loads the built React app in a Webview pointed at
`http://127.0.0.1:8000`.  On narrow widths (≤ 520 px) the session list
and file explorer are automatically hidden so the chat fills the panel.

## Architecture

```
vscode-extension/
├── extension.js          ← activate(), CodingAgentViewProvider, startApiInTerminal()
├── package.json          ← manifest: view, commands, activationEvents
├── images/
│   ├── sidebar-icon.svg  ← Activity Bar icon
│   └── icon.png          ← Marketplace icon (128×128, add manually)
└── .vscodeignore

ui/
├── src/
│   ├── App.jsx           ← React app (unchanged logic)
│   └── index.css         ← + narrow-screen @media rule for sidebar view
├── vite.config.js        ← + base: './' for relative asset paths
└── dist/                 ← generated by `npm run build`  ← loaded by webview
```

## Content-Security-Policy

The webview CSP (injected dynamically into the built HTML) allows:

| Directive       | Allowed sources |
|---|---|
| `script-src`    | `webview.cspSource` (VS Code nonce scheme) + per-load nonce |
| `style-src`     | `unsafe-inline` + `webview.cspSource` + Google Fonts API |
| `font-src`      | `fonts.gstatic.com` + `webview.cspSource` |
| `connect-src`   | `http://127.0.0.1:8000` + `ws://127.0.0.1:8000` |
| `img-src`       | `webview.cspSource` + `data:` + `blob:` |

Everything else is blocked (`default-src 'none'`).
